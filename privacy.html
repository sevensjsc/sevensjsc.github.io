QUOTES YouTube Automation(이하 "이 앱")은 유튜브 채널 QUOTES | Daily Wisdom 운영자가 자기 채널에 영상을 올리기 위해 개인 PC에서만 사용하는 도구입니다.

QUOTES YouTube Automation ("the app") is a personal tool that runs only on the operator's own PC to upload videos to the operator's own YouTube channel, QUOTES | Daily Wisdom.

1. 접근하는 Google 사용자 정보 / Google user data accessed

  • YouTube 채널 정보(채널 ID·이름) — 올바른 채널인지 확인하기 위해 / Channel ID and title, to confirm the correct channel.
  • 영상 업로드 권한(youtube.upload) — 운영자가 고른 영상을 운영자 채널에 올리기 위해 / Permission to upload the videos the operator selects to the operator's channel.
  • 읽기 권한(youtube.readonly) — 채널·영상 정보와 공개 영상 검색 결과를 조회하기 위해 / Read access to channel and video information and public search results.

2. 저장 / Storage

Google 로그인 토큰은 운영자 PC에만 저장되며, Windows DPAPI로 암호화되어 그 PC의 같은 Windows 사용자만 풀 수 있습니다. Google API 외의 서버로 전송하지 않습니다.

OAuth tokens are stored only on the operator's PC, encrypted with Windows DPAPI so that only the same Windows user on that PC can decrypt them. They are never sent to any server other than Google's APIs.

3. 공유 / Sharing

Google 사용자 정보를 제3자에게 판매·공유·전송하지 않으며, 광고에 사용하지 않습니다.

Google user data is not sold, shared, or transferred to any third party and is not used for advertising.

QUOTES YouTube Automation's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 권한 취소와 삭제 / Revoking access and deletion

Google 계정 → 보안 → 서드파티 앱 및 서비스에서 이 앱의 권한을 언제든 취소할 수 있습니다 (myaccount.google.com/connections). PC에 저장된 토큰은 운영자가 직접 삭제할 수 있습니다.

You can revoke the app's access at any time from Google Account → Security → Third-party apps and services. Tokens stored on the PC can be deleted by the operator at any time.

5. YouTube API 서비스 / YouTube API Services

이 앱은 YouTube API 서비스를 사용합니다. 사용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

This app uses YouTube API Services. The YouTube Terms of Service and the Google Privacy Policy apply.
